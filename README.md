# Tic Tac Toe

A two-player Tic Tac Toe game built with **HTML, CSS and vanilla JavaScript** (no libraries).

## Features
- Two players on one device (X goes first)
- Detects wins (rows, columns, diagonals) and draws
- Winning squares are highlighted
- Scoreboard for X wins, O wins and draws
- **New Game** keeps the scores, **Reset Scores** clears everything
- Keyboard and screen-reader friendly (every square has a label)
- Dark theme and mobile friendly

## How to run
No installation needed. Download the files and open `index.html` in your browser.

## What I practiced
- Arrays and game state
- Checking winning combinations with loops
- Creating elements with JavaScript and handling click events
- Updating the page from data (`render` function)
